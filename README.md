# FB Marketplace 自动发布助手

一个 Manifest V3 的 Chrome 浏览器插件:把常用的商品信息保存成模板,在你自己已登录的
Facebook 账号里自动打开 Marketplace 发布页,自动填好标题 / 价格 / 类别 / 成色 /
描述 / 地点 / 照片,减少重复手动录入的时间;可以选择让它自动点击「发布」,也可以
只让它自动填表、由你本人最后确认再点发布。

## 重要说明与风险提示

- 插件只在**你自己浏览器里已登录的 Facebook 账号**上操作,不存储你的账号密码,
  也不做任何绕过登录 / 验证码 / 风控检测的事情。
- Facebook 的用户协议对自动化行为有限制,频繁或大批量自动发布**有可能触发平台
  风控,导致账号或商品被限制**。建议:
  - 默认使用「**自动填表 + 手动点击发布**」模式(设置里不勾选「自动点击发布」),
    每条 listing 都由你本人最终确认后再发布;
  - 如果要开启全自动发布,把两次发布的间隔设置得宽松一些(默认 60–150 秒随机),
    不要一次性排几十条一起跑;
  - 因使用本插件导致的账号或商品限制等后果,由使用者自行承担。
- Facebook 页面结构经常调整。插件用「按可见文字 / aria-label 匹配」的方式定位
  输入框和按钮,如果 Facebook 改版导致某个字段找不到,会在发布日志里报告具体
  是哪一步失败,需要自行调整 `content.js` 里 `LABELS` 对应的文字,或改为手动
  完成那一步。

## 安装方法(开发者模式加载)

1. 下载 / 克隆本仓库到本地。
2. 打开 Chrome,访问 `chrome://extensions`。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」,选择本项目所在文件夹。
5. 安装完成后,点击工具栏里的插件图标打开面板。

## 使用方法

1. 在插件面板的「新增商品」表单里填写标题、价格、类别、成色、地点、描述,并
   选择商品照片,点击「保存商品」;可以重复添加多条,组成一个发布队列。
   - **类别 / 成色的文字需要和 Facebook Marketplace 发布页面上显示的选项文字
     完全一致**(比如中文账号写「电子产品」「二手 - 良好」,英文账号写
     `Electronics`、`Used - Good`),否则插件在下拉列表里找不到对应选项。
2. 在「发布设置」里设置两次发布之间的间隔秒数,以及是否开启「自动点击发布」。
3. 点击「开始发布队列」,插件会依次为每条「待发布」状态的商品打开一个新标签页
   并自动填表;
   - 未开启自动发布时,标签页会停在填好表单、等待你确认的状态,你检查无误后
     手动点击 Facebook 页面上的「发布」按钮即可;
   - 开启自动发布后,插件会自动翻页并点击最终的「发布」按钮。
4. 面板下方的日志会显示每一步的处理结果。失败的商品可以点「重设为待发布」重新
   尝试,或点「编辑」修改信息后再发布。

## 文件结构

- `manifest.json` — 插件配置(Manifest V3)
- `background.js` — 后台队列调度(用 `chrome.alarms` 控制发布间隔、打开标签页、
  记录日志——因为 MV3 的 service worker 闲置一段时间会被系统回收,不能用
  `setTimeout` 硬等几十上百秒)
- `content.js` — 注入到 Facebook 发布页面的脚本,实际找到表单并填写
- `popup.html` / `popup.js` / `popup.css` — 插件弹出面板界面
- `storage.js` — 本地存储(`chrome.storage.local`)的公共读写方法

## 已知限制

- 目前只处理商品类目的发布流程(`/marketplace/create/item`),车辆、房屋租售等
  其他类目页面结构不同,尚未适配。
- 图片通过 `DataTransfer` 注入到文件选择框实现,单张图片建议不要太大(几 MB
  以内),过大的 base64 图片会让插件的本地存储变慢。
- 不包含任何验证码 / 短信验证 / 人机验证的绕过逻辑,如果 Facebook 弹出验证,
  需要你手动完成后再继续。
